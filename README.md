# Fluo

**轻盈地刷微博，原生地用鸿蒙。**

为 HarmonyOS 打造的原生微博第三方客户端。

清新的鼠尾草绿、沉浸式界面，让注意力回到你关心的人与内容。

## 为阅读留出更多空间

在推荐里发现新鲜事，在关注里跟进熟悉的人。

Fluo 用简洁的内容卡片呈现图文与视频，将导航和评论入口收进悬浮底栏，让浏览、阅读与互动自然衔接。

## 功能体验

### 发现你感兴趣的内容

- **推荐与关注**：切换两种信息流，浏览动态、刷新与继续加载。
- **热搜与搜索**：查看热搜榜，输入关键词查找微博内容。
- **用户主页**：了解用户资料，查看对方发布的微博。

### 读完一条微博，也看见它的讨论

- **长文阅读**：在详情中展开正文，继续阅读完整内容。
- **图片与视频**：预览图片、播放视频，在画面内控制进度与倍速。
- **评论与回复**：查看评论和楼中楼讨论，切换评论排序。
- **话题与链接**：从正文中的话题、用户提及和网页链接继续探索。

### 想回应时，随手表达

- 点赞、收藏与关注，留下你感兴趣的内容和人。
- 评论、回复与转发，参与正在发生的讨论。
- 发布文字和图片，用表情补充心情。
- 查看消息，以及自己的微博、收藏和点赞记录。
- 调用鸿蒙系统分享，将内容分享出去。

账户相关功能需要登录，实际可用性受微博接口与账户权限影响。

## 属于鸿蒙的原生体验

Fluo 的主要界面由 ArkTS / ArkUI 原生构建，而不是将微博网页包装成应用。

- **沉浸式悬浮栏**：导航与评论入口采用 HDS 原生材质及渐变背板。
- **清新主题**：以鼠尾草绿为默认强调色，也可以选择自己喜欢的配色。
- **舒适阅读**：支持深浅色模式与字体缩放。
- **适应不同屏幕**：根据窗口宽度调整内容与导航布局，持续打磨手机、折叠屏和平板上的体验。

## 开始使用

1. 首次打开 Fluo，阅读并确认隐私说明。
2. 浏览首页推荐，或前往热搜查找感兴趣的内容。
3. 在「我的」中打开微博登录页，自行完成登录后，使用关注流与账户互动功能。
4. 点开一条微博，阅读正文、查看图片视频，或进入评论参与讨论。

公开内容可尝试以访客身份访问，但微博可能要求登录或验证。遇到登录失效、验证码或访问限制时，请按微博的提示处理。

## 由你决定每一次互动

Fluo 不提供自动点赞、定时发布或批量互动。点赞、评论、转发和发布，只响应你主动发起的操作。

登录态保存在本机应用存储中，用于向微博服务发起授权请求，不向本项目控制的第三方上传或共享。详情请阅读 [隐私说明](docs/PRIVACY.md)。

## 一起让 Fluo 更好用

Fluo 正在持续开发，部分功能可能因微博接口变化而暂时不可用，不同设备上的体验也在不断完善。

遇到问题或有新的想法，欢迎前往 [Issues](https://github.com/HaiYangMa13/fluo/issues) 告诉我们。附上设备型号、系统版本和复现步骤，会更容易定位问题；请勿提交登录凭据或未脱敏的私人内容。
