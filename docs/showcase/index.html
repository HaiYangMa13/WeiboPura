ArkUI 代码架构与 1:1 实现规范审查

以上原型完全废弃通用概念模板，完全按 Fluo 源代码中的 ArkUI 控件、HDS 材质及设计规范对齐：

1. 首页与沉浸式 HDS Dock

  • 顶栏分段器：Index.ets: Row.backgroundColor('rgba(..., 0.08)') + 20vp 圆角。
  • 微卡神评：WeiboHomeTab.ets: HotCommentBox 鼠尾草绿标签 + 作者 + 精选评语。
  • 悬浮底栏：common/WeiboDockStyle.ets: createWeiboDockStyle 共享 IMMERSIVE 材质。
  • 手势判定：common/WeiboTabSwipe.ets 原生 PanGesture 单向独占，拒绝子点击误吞。

2. 发现与五分类搜索

  • 搜索胶囊：WeiboHotSearch.ets 42vp 高度、带清除与即时建议能力。
  • 五分类切换：WeiboSearchResult.ets 综合=1, 实时=61, 用户=3, 视频=64, 图片=63。
  • 置顶直达：HighlightUserCard 48vp 头像带金 V/蓝 V 认证角标与粉丝信息。
  • 搜索历史：CacheManager.weibo_search_history 自动持久化并保留前 10 条。

3. 微博正文与三栏联动

  • 标题栏居中：WeiboPostDetail.ets: HdsTitleBar 真实显示「微博详情」与返回/分享。
  • 人文精排：方案 A 现代人文排版，16.5vp 字号 / 1.76 行高 / 盘古之白中英留空。
  • 联动三栏：DetailTabsHeader 转发(4) / 评论(33) / 赞(100) 支持手势防误触横滑。
  • 原生底栏：BottomComposer 沉降输入胶囊 + 点赞/收藏/评论高频按钮并列。
